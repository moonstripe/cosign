How much of a person's voice is orthography?
Glick et al. · working draft · LFM3-1.7B + Qwen3.5-4B · 12 Enron authors
When a writer's casing and punctuation are more unusual, orthography gives more of the measured “voice” (ρ = 0.71). A rewrite that changes only casing and punctuation gets almost the same score as a full style vector (+0.25 and +0.27).
Style metrics see the surface first. Voice must come from a deeper level than punctuation.
Gradient-free weight editing reduces overthinking in Qwen3.8-27B
Bennington, Kaelar, Lee, Edwards, Glick, Danks · Concept Country 2026
We read directions from forward passes. We wrote them into nine down-projections as rank-one edits. Results: +4.3 GPQA, +13.0 LiveCodeBench, −30% thinking tokens. A random edit of the same size had no effect.

The dials

Each of the four moods is a weight-space program.

01
The model writes its own contrast pairs
The model writes the same opening in two registers. We remove the mood words. Thus, the dial cannot learn the word.
02
An agent writes a rank-1 edit
The agent has 15 forward passes and no gradients. It writes the edit into the MLP outputs of layers 7–17.
03
The edit must do better than a random edit
The random edit has the same size and a random direction. We test on held-out prompts and read each sample.
04
The wheel sets α for each token
The axes are tense–calm, tender–cold, playful–grave and lush–plain. We built three dials at the same time on Modal.

The harness

An RL-style environment for an agent that programs weights.

Wℓ′​=Wℓ​+αt​Aℓ​Bℓ⊤​
Wℓthe weights of layer ℓ (MLP output, layers 7–17)
A B⊤a rank-1 edit that the agent writes, from the model's own mood text minus the opposite text
αtthe wheel position for token t, from 0 (the original model) to 1
The agent reads the weights in a Python kernel. It can run the model only with 15 forward passes. It cannot use gradients.
The edit must do better than a random edit of the same size. tense–calm, 16 held-out pairs: +1.19 for the dial, +0.02 for the random edit.

Limitations

Pangram possibly does not know LFM3 text.

01We do not know if the Pangram training data includes text from LFM3 models.
02If it does not, a low AI score can show a gap in the detector. It does not always show text that reads as human.
03Thus, the 48% result can come from the pretraining data of the detector, not from the dials.
Next test: Write the same branch with the dials off. Then compare the Pangram scores of the two branches.
